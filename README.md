# creative-portfolio 🎨✨

Welcome to my creative space! This repository serves as a central hub for my personal artistic projects, visual designs, and media files. It’s a collection of ideas brought to life across different mediums.

## 📂 What's Inside

The repository is organized into three main categories:

*   **🎨 Drawings & Sketches:** Digital illustrations, fun coloring and sketching
*   **✨ Canva Designs:** Social media graphics, design layouts, and presentation decks built using Canva templates and custom elements.
*   **📷 Photography:** Visual storytelling through captured moments, with a mix of scenery and memorable shots.

## 🛠️ Tools Used

*   **Illustration:** Procreate
*   **Design & Layout:** Canva
*   **Photos:** iPhone 16 Pro
